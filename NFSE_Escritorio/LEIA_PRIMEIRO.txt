ESTADO
Este pacote contem o codigo para construir e abrir a DEMONSTRACAO.
Nao e um instalador .exe. Nao emite notas fiscais.
Somente o computador principal acessa a demonstracao (127.0.0.1).
Acesso pela rede e emissao real continuam bloqueados.
Os comandos ainda precisam ser validados no Windows do escritorio.

COMO COMECAR NO WINDOWS
1. Extraia o ZIP completamente antes de executar qualquer comando.
2. Abra a pasta NFSE_Escritorio, que contem package.json e a pasta scripts.
3. Na barra de endereco do Explorador de Arquivos, digite powershell e pressione Enter.
4. Instale as dependencias usando o Bun cujo funcionamento voce ja confirmou:

& "$env:USERPROFILE\.bun\bin\bun.exe" install --frozen-lockfile

5. Se concluir sem erro, execute UM comando por vez:

.\scripts\escritorio.cmd verificar
.\scripts\escritorio.cmd construir
.\scripts\escritorio.cmd iniciar --abrir

O primeiro verificar pode mostrar que o build local ainda nao existe.
O construir gera esse build. Se algum comando apresentar erro, pare e registre a mensagem.

Para conferir se esta rodando:
.\scripts\escritorio.cmd estado

Para parar:
.\scripts\escritorio.cmd parar

Nao use construir --modo api agora: os requisitos fiscais ainda nao estao configurados.
